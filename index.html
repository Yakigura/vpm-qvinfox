QvInfoX VPM

VRChat Creator Companion（VCC）用の、パッケージ一覧です。

VCC に追加する

ボタンが効かないときは、VCC の Settings > Packages > Add Repository に、次の URL を貼ってください。

https://yakigura.github.io/vpm-qvinfox/index.json

一覧を追加しただけでは、パッケージは入りません。プロジェクトの Manage Project で、使いたいものを選んで追加します。

パッケージ

QvInfoX 1.0.0

Non-invasive monitoring tools for QvPen: sync progress, ink load, and per-pen preview indicator.

説明 ・ 更新履歴 ・ 利用規約

自動で入る部品

次のものは、上のパッケージと一緒に入ります。単独で入れる必要はありません。

  • Qv Scene Setup 1.0.0 — Reversible per-scene installation records for Yakigura tools.
  • QvInkPreview 1.0.0 — QvPen の各ペンの後ろに、現在のインクと同じマテリアル・色・太さの短い線を表示する VPM パッケージ。

ご注意

QvPen が必要です。QvPen は、この一覧にはありません。先に導入してください。

新しい版が出ると、VCC の Manage Project に、更新できる、と出ます。以前の版も、VCC のバージョン選択から選べます。
